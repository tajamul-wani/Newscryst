# NewsCryst

A modern, responsive news aggregator built with React, Vite, and Tailwind CSS.

## Features
- Global & Categorized News
- Search Integration
- Save to Favorites
- Persistent Dark Mode

## Setup
1. Clone the repository
2. Run `npm install`
3. Add your API key to `.env` as `VITE_NEWS_API`
4. Run `npm run dev` to start the development server.

## Deployment
Configured for deployment on Netlify via GitHub integration.
